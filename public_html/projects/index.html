Projects

Interactive experiments, mostly with canvas, mostly with math.

  • Mandelbrot Explorer

    Click to zoom into the Mandelbrot set. The banded escape-time layers stay crisp all the way down.

    • Deep zoom past float64 precision using perturbation theory
    • Renders across every CPU core with web workers
    • Adjustable iterations, sizes and high-resolution image export
    • Canvas
    • Web Workers
    • BigInt

  • Chaos Game Paths Plotter

    The chaos game moves a point at random between a series of attractors. This plotter visualizes ranges of magnitude when moving toward the attractors.

    • Adjustable magnitude and quality
    • Predefined fixed and variable magnitudes
    • Canvas
    • jQuery
    • Drawer

  • Node Diagram

    A customizable node diagram, built for a physician to visualize patient case files.

    • Zoomable, pannable worksheet
    • Double-click a node to edit its contents
    • Click one node, then another, to connect them
    • Canvas
    • KineticJS
    • Bootstrap

  • Arcs Drawing Tool

    A small drawing tool for symmetric circle arcs.

    • Symmetric arc calculation
    • Canvas
    • Drawer

  • Differential Equation Visualizer

    Enter your own differential equations and visualize them.

    • Custom differential equations
    • Canvas
    • ProcessingJS

  • Water Skimmers

    On a lake in Whiteshell park I watched water skimmers perform their evening ritual: when two get too close they repel each other in opposite directions. Click the canvas to add more skimmers.

    • Canvas
    • Drawer
